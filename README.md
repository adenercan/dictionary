# Dictionary App

A clean and customizable **dictionary web application** built to practice real-world JavaScript concepts such as **API consumption, async/await, fetch**, and basic **UI customization features**.

This project is part of my frontend development journey and focuses on building a **functional, readable, and user-friendly** application.

## 🚀 Features

- Search for English words
- Fetch word definitions from an external API
- Asynchronous data handling using `fetch` and `async/await`
- Error handling for invalid or missing words
- Theme customization:
  - Light & Dark mode
  - 3 different font options
- Clean and minimal user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Fetch API

## 🎨 UI & Customization

- Users can switch between **Light and Dark themes**
- Users can choose from **3 different font styles**
- Theme and font changes are applied dynamically without page reload
- Focus on accessibility and readability

## 🔍 What I Focused On

- Working with **real APIs**
- Handling asynchronous operations using `async/await`
- Managing UI state (theme & font)
- Writing clean and maintainable JavaScript
- Building a complete feature-focused project

## 🧠 How It Works

1. User enters a word into the input field
2. The app sends a request using the **Fetch API**
3. Data is handled asynchronously with `async/await`
4. Word definition is rendered on the UI
5. Theme and font preferences can be changed instantly
6. Errors are handled and displayed gracefully
